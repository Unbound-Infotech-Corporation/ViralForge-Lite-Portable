# ViralForge Lite Portable (Windows)

Friend-clickable **Studio Setup** for Windows 10/11. Lite is selected. **No Wan or LTX GPU weights are in the zip.**

## Download (send this to a friend)

**Release page:** https://github.com/Unbound-Infotech-Corporation/ViralForge-Lite-Portable/releases/latest

**Direct zip:** https://github.com/Unbound-Infotech-Corporation/ViralForge-Lite-Portable/releases/download/v0.2.0-lite/ViralForge-Lite-Portable.zip

1. Unzip
2. Double-click `Start.bat` (or `ViralForgeSetup.bat`)
3. Setup opens on **Lite**. Dry-run / Ken Burns cinema works without a 40–150 GB download.
4. Upgrade later in the same window: sidebar **Regular** or **Maximum**.

Full friend notes: [portable/FRIEND-README.md](portable/FRIEND-README.md)

The Lite / Regular / Maximum chooser stays in the GUI. Regular and Maximum download Hugging Face weights only when you pick those packs.
